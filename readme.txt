Megabonk Mod


Weapons
The Sword: Bonk enemies up close. Upgrades increase Range and Knockback.
The Bow Upgrades unlock Triple Shot and Explosive Arrows.
Magic Staff:  Upgrades unlock Fireballs, Ice, and Split Shots.

 Wave Survival System
Manual Wave Start:**  Press 'i' when you are ready for the next wave.
Loot Drops:** Monsters drop armor and upgrades upon death to keep you in the fight.

Third-Person Mode
See your character in action. Press 'e' to toggle between First-Person and Third-Person camera views instantly.

 How to Play

- Navigate to your Quake 2 installation folder.
- copy the mymod folder to your quake 2 directory. 

Make The Shortcut 
1.  Find quake2.exe in your game folder.
2.  Right-click it and select Create Shortcut.
3.  Right-click the new shortcut and select Properties.
4.  In the Target box, add the following to the very end of the line:
    +set game mymod or the name of the modfolder
5.  Click OK. Double-click the shortcut to play
